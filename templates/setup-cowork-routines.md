# Set up Cowork routines

Run this prompt once in Cowork after installing 2nd Brain. It will create all the scheduled routines that keep your wiki alive.

---

Create the following scheduled routines in Cowork. For each one, use the exact name, description, schedule, and instructions below.

---

## 1. Wiki update
**Schedule:** Every day at ~10:00  
**Instructions:**
Use the translate and synthesize prompts in the /prompts folder to translate raw files from /raw into the /wiki.

Read transcripts of calls to find and capture details, ideas, facts, important things to memorise, everything that will be valuable for thinking patterns. Calls are often brainstorms and contain a lot of hidden gold, thoughts, reflections and ideas.
